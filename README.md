# life-design（人生设计师）

一个 Claude Code Skill：受斯坦福 d.school《Designing Your Life》训练，融合"先扩散后收敛"的思维方法，陪你把模糊的人生困惑走成一张自己愿意迈出去的行动地图。

它不替你做决定。方案从你心里长出来，它只负责照亮和反射。一次对话约 40–90 分钟，最终可结晶成一份《个人人生设计蓝图》。

## 适用场景

- 想规划人生、面临方向选择、感到迷失卡住
- "不知道接下来该往哪走""感觉找不到发力的方向"
- 想认真想一想五年后想成为什么样的人
- 想带朋友一起体验一次人生梳理

触发词：`规划人生`、`人生设计`、`设计人生`、`我迷失了方向`、`odyssey plan`、`designing your life`、`人生蓝图`

**不适用**：具体项目排期、日程管理、纯知识问答。

## 它怎么工作

核心是**一次只问一个问题**，并且先复述、再重构——因为表层烦恼往往不是真问题。

流程（灵活推进，不必死板按序）：

| 步骤 | 内容 |
|------|------|
| 0 | 找真问题：听困扰 → 复述 → 重构 |
| 1 | 四仪表盘：健康 / 工作 / 玩乐 / 爱，各打 0–10 分 |
| 2 | 工作观 & 人生观：做一致性检查，打架处藏着线索 |
| 3 | 能量地图：区分"回血"与"消耗"，点破被动逃避式休息 |
| 4 | 心流时刻：最近哪个瞬间你觉得自己最像活着 |
| 5 | 重力问题 vs 可设计问题：别把力气耗在动不了的事上 |
| 6 | 锚点/执念：找出反复卡住的模式，温柔地重新定义 |
| 7 | 奥德赛计划：三个五年版本（现有路径 / 此路不通 / 不为钱和面子） |
| 8 | 原型行动：拆出最小、最便宜、最不需要鼓起勇气的一步 |
| 9 | 失败免疫：人生是无限游戏，失败是数据不是代价 |

## 产出

当你说"整理成蓝图 / 文档"时，它会忠实结晶成《个人人生设计蓝图》：

四仪表盘 → 重力问题 vs 可设计问题 → 工作观与人生观 → 能量与心流 → 锚点解构 → 三个奥德赛版本 → 原型行动清单 → 失败免疫

保留所有关键洞察、被否决的选项和故意留白处。这份文档是"给你的出发点"，不是替你填满的日程表。

## 设计原则

- 你是思维合伙人，不是发号施令的专家
- 不灌输、只反射——把你自己的话还给你
- 尊重边界：不贴分类标签，你说了"不想再往这想"就立即停下
- 温暖但不绕弯：先给结论，直接，零客套
- 起点不需要正确，只需要能滚
